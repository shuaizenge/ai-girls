# MiMo / 小米

设计基准：**甶丶**。识别特征：银白双马尾、橙黑外套、mi 与 MiMo 标识、一只白袜一只黑袜，抱着白兔。

ZipZipPipe 的公开合集里没有小米 MiMo。这套取自作者甶丶 2026-08-30 的动态《娘化mimo》，立绘和三视图是同一作者。投稿说明为 CC BY-NC，允许署名和非商业使用，并允许收录和下载。
