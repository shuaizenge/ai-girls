# Seedance

设计基准：**ZipZipPipe**。识别特征：紫蓝单马尾、蓝白科技装、SEED 工牌、豆包玩偶。

这是 ZipZipPipe 画的 Seedance 拟人，工牌上写的是 SEED。仓库里的 [豆包官方头像](../doubao/) 仍是官网素材，不与这张立绘混放。
